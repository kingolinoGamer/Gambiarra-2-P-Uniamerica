# Pokédex - Gambiarra 2P

Projeto em grupo da Uniamerica: uma Pokédex para consultar Pokémon, desenvolvida seguindo práticas ágeis (Scrum) e com documentação de requisitos.

Segundo projeto mensal

## Escopo do projeto
- Implementação das interfaces planejadas da Pokédex utilizando HTML + CSS + JavaScript
- Interfaces dinâmicas, utilizando manipulação do DOM
- Conexão com a API PokeAPI

## Tecnologias
- HTML, CSS e JavaScript
- PokeAPI
